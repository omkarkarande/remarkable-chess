Offline single-player chess for the reMarkable 2.

## Features

- Native AppLoad interface designed for e-ink.
- Offline Stockfish opponent with adjustable Skill Level (0–20).
- Legal-move enforcement, including check and self-check protection.
- Check, checkmate, and stalemate detection.
- Castling and en passant.
- Choose Queen, Rook, Bishop, or Knight when promoting a pawn.
- Player colour is randomly assigned for new games; the board rotates so the player is always at the bottom.
- Undo to the latest position where it is the player's turn.
- Saved games resume automatically.
- All game data stays in the app-owned configuration directory.
